# Hexa Sort

Jeu de tri de piles hexagonales en 2.5D : glisse les piles, enchaîne les combos, collecte les couleurs par 10.

**Jouer :** https://beboxos.github.io/hexa-sort/

Sur téléphone, le jeu s'installe comme une appli :
- **iPhone (Safari) :** bouton Partager → « Sur l'écran d'accueil »
- **Android (Chrome) :** menu ⋮ → « Ajouter à l'écran d'accueil » / « Installer l'application »

Il fonctionne ensuite hors ligne, et la progression est sauvegardée sur l'appareil.

Un seul fichier HTML (canvas), sans dépendance externe.
